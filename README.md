## Wallet Setup

The app uses a connected Web3 wallet for access; Google OAuth, email login, and NextAuth sessions are not used. Install MetaMask, copy `.env.example` to `.env.local`, and configure the public wallet/contract settings:

- `NEXT_PUBLIC_LOCALHOST_RPC` for the local Hardhat node.
- `NEXT_PUBLIC_CONTRACT_ADDRESS_LOCALHOST` for the deployed insurance contract.
- `NEXT_PUBLIC_WALLET_CONNECT_PROJECT_ID` for RainbowKit wallet connection.

Start the app with `npm run dev`, connect MetaMask, and use the local Hardhat network (chain ID `31337`) for local contract interactions.
